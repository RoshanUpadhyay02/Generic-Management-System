## 📌 Overview

Generic Management System is a desktop application developed using **Python** and **Kivy** to simplify day-to-day management operations.

The application provides an intuitive graphical interface with dataset management capabilities and demonstrates software engineering concepts including UI design, workflow planning, and desktop application development.

---

## Features

- Desktop GUI
- Dataset management
- Kivy-based interface
- Multimedia support
- Software design documentation
- User-friendly navigation

## Tech Stack

- CSV
- OpenCV (if required)
